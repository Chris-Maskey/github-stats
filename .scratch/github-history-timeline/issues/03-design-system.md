# 03 — Design system foundation

**What to build:** The visual system the whole app renders on: Geist Pixel for display type (timeline ticks, big numbers, sync headers), Geist Sans for body text (pixel fonts display-only, never below ~12px), Skiper UI components wired via the shadcn registry, Animate UI icons (animated Lucide via Motion), Dot Matrix loaders installed, and the Tailwind theme tuned to the retro-digital aesthetic. The Skiper UI free-tier attribution credit is placed in the app (footer/about).

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] Geist Pixel + Geist Sans installed and applied as CSS variables (display vs body split respected)
- [ ] Skiper UI components installable and rendering in-app
- [ ] Animate UI icons rendering
- [ ] At least one Dot Matrix loader rendering
- [ ] Tailwind theme carries the pixel/digital aesthetic coherently
- [ ] Skiper UI attribution credit visible (free-tier license requirement)
