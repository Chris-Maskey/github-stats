# Retrospective narration is a stats-only wrapper over deterministic aggregates

The Retrospective (an LLM-narrated, per-year story of the synced history) is generated by handing the model a stat block per year — counts, top repo, streaks, ~5–10 deterministically sampled titles — never the raw history, and the narration may assert only what those stats say. Holes (years with no synced activity) render as a deliberate, moodless "no activity synced" chapter; the page-level honesty line is the only place the app speaks about what GitHub doesn't know, and the two never merge. This exists because a free-wheeling LLM over decades of gaps produces confident wrong autobiography — worse than a boring right one — and because stats-only keeps the prompt at ~1KB/year (cost and quality both win).

Consequences: the output is cached in SQLite keyed on a stats fingerprint, so a changed fingerprint flags the story as stale and regeneration is a deliberate click (never automatic — generation costs money and the crawl-complete moment is the least stable data moment). Generation is one call per chapter plus the opener, from a single `(prompt) → text` seam, currently hardcoded to the Gemini 2.5 Flash free tier (~1,500 req/day, no card) — the free-tier training caveat is moot because every sent token is public GitHub content. A provider swap is a one-file change by design.
